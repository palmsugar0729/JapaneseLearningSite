# v2.4 迭代计划

## 技术栈决策

**uni-app (Vue 3) + Vite 模式**，一套代码编译到 Web (H5) 和微信小程序。

- 新建 `miniprogram/` 目录，现有 `codes/` 不动作为参考
- 可复用：composables（SRS 算法等）、types、utils/shuffle
- 需适配：storage（→ uni.getStorageSync）、路由（→ pages.json）、图表（→ echarts-for-uniapp）、CSS（玻璃拟态 → 扁平/卡片风格）

## 数据策略

16,427 词不走本地打包，通过后端 API 按需加载，解决小程序包体积限制。

## 登录方案

| 平台 | 方式 | 备注 |
|------|------|------|
| 微信小程序 | 微信一键登录 (`uni.login` → code → openid → JWT) | 个人可用 |
| Web | 账号密码 | 已有，不改 |

后端新增 `/api/auth/wx-login` 路由。

**Why:** 现有的 Web SPA 只覆盖浏览器端，微信小程序有更低的触达门槛，且 uni-app 一套代码维护成本可控。
