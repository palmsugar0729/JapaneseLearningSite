# JapaneseLearning 项目定位

独立的日语学习 Web SPA，Vue 3 + TypeScript + Vite 前端，Express + SQLite 后端。

核心功能：SRS 单词卡（SM-2）、练习题库、学习统计图表、教科书同步、用户系统。

**用户：** palmsugar，日语教师，目标学生群体使用。

**技术栈：** Vue 3 + TS + Vite + SCSS（前端），Express + better-sqlite3 + JWT（后端），ECharts（图表）。

**Why:** 从 palmsugar-lab 子模块拆分为独立应用，方便独立部署和维护。
**How to apply:** 技术选型和架构决策参考此文件。
