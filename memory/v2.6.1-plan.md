# v2.6.1 教科书词库换代（2026-09-19）

教科书词库原本只有 4 课（175 词），这次把第一本书的 **16 课全部入库（920 词）**，并给词库补上「LEVEL」维度。

**状态：代码完成、构建与数据核对通过 → ⏳ 等用户浏览器验收，未提交 git、未部署。**

完整记录见 `docs/开发日志.md` 2026-09-19 条目；PRD 2.4 / 4.1 节已同步。

## 核心结构决策

**两套词库维度不同，永远不要混着统计。**

| 词库 | 路径 | ID | 维度 |
|------|------|-----|------|
| JLPT | `content/japanese/words/{N5..N1}.json` | `n5-001` | JLPT 级别 N5~N1 |
| 教科书 | `content/japanese/textbook/level-N/unit-NN.json` | `tb1-01-001` | 教材 LEVEL + 单元 |

教科书单词的 `level` 字段填的是 `N5`（**难度参考**），但它不是 JLPT 词库的成员。混在一起会把 N5 分母从 601 撑到 1521，进度条从 `12/601` 失真成 `12/1521`。级别进度卡片与统计页详情表已拆成两组。

加一本新教材：`level-2/` `level-3/` `level-4/` 目录**已预建好**（`.gitkeep` 占位）。把词表放进 `docs/vocabulary_files/LEVEL N/`，跑 `python codes/import_textbook_excel.py N` 即可，ID 自动成 `tb2-…`，前端的 LEVEL 按钮和进度分组自动生成，**不用改代码**。

> `codes/import_textbook_excel.py` 是 v2.6.1 新加的 Excel→词库导入脚本（补上原有 `build_vocab_excel.py` 的下游）。**规则已编码进脚本**：词性剥方括号、ID 命名、`textbookLevel`、例句留空等，下一轮别再手写 JSON。已验证它能逐字节复现 LEVEL 1 的 16 个文件。

## 三个必须记住的坑

1. **教科书没有单元标题数据，别再往代码里塞。** 早先代码里硬编码过 16 条课次标题（`api/vocabulary.ts` 的 `unitTitles`）。核对发现：前 6 课标题确实由本课生词拼成，**第 7~16 课与本课生词零重合**。判定为——当初只有前 4 课有真实数据，所以标题 1~4 是照书写的；第 5~16 课当时没有词表，那 12 条是早先某次 AI 会话**凭空生成**的，一直没人核对。已删除。需要真标题只能从书上抄。

2. **改教科书词条的 ID 或内容会打乱用户进度。** 进度按 `word_id` 存（服务端 `srs_progress` 表 + 前端 localStorage）。换代时若复用 ID，同一个 ID 指向的词换了，「已学过」标记就跑到别的词上。而且新旧 ID 形态完全一样（都是 `tb1-0N-*`），**没法用 SQL 模式匹配区分**，只能靠 `meta` 表标记位做一次性迁移（见 `server/src/db.ts`）。

3. **部署时后端必须和新前端一起上。** 只更新后端的话，仍在使用旧版前端的用户下次同步会把已清掉的 `tb1-*` 旧记录推回来。注意 `PUT /api/progress/srs` 是**全量替换**语义（前端没传来的 key 会从服务端删掉），所以旧前端一旦同步就会复活旧数据。

## 数据来源约定

- 来源是人工整理的 Excel（列：日语 / 读音 / 声调 / 词性 / 中文意思），**没有例句数据**，`example` / `exampleTranslation` 保持空字符串
- 词性入库时要**剥掉外层方括号**（`[名・他動3]` → `名・他動3`），与 JLPT 词库写法一致
- 有 32 条寒暄语（こんにちは 等）来源表里没有词性，**留空不编造**，界面按空值不渲染标签
- 有 4 个词跨单元重复（`何` / `～中` / `北京` / `辛い`），按原文保留，ID 与 SRS 进度各自独立

## 顺带发现的既有缺陷（未修）

**未登录用户的背单词进度每次刷新都会丢。** `App.vue` 只在有 token 时调 `initSRSFromServer()`，而该函数是唯一从 `localStorage` 读回 `srs-progress` 的地方；匿名用户刷新后 `progressMap` 为空，下次复习时 `saveAll()` 又把整个 map 覆盖写回，等于擦掉之前的进度。与本次改动无关，待用户决定是否修。

**Why:** 学生会拿教科书当主线学习，词库必须和教材对齐；而 LEVEL 维度是加第二本书的前提，现在打好基础后续零改动。
**How to apply:** 后续加 LEVEL 2、或动教科书词条时，先看上面三个坑。相关：[[word-data-level-field]]、[[v2.6-plan]]、[[server-config]]
