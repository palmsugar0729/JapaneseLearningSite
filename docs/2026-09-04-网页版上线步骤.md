## Nginx 配置（完整替换用）

```nginx
server {
    listen 80;
    server_name jplearning.palmsugar.cn;

    # 前端静态文件（dist 上传后的位置）
    root /opt/japanese-learning/JapaneseLearningSite/codes/web/dist;
    index index.html;

    access_log /var/log/nginx/japanese-access.log;
    error_log  /var/log/nginx/japanese-error.log;

    # API 反代到 Node.js 后端
    location /api/ {
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;

        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # SPA 前端：找不到的文件回退到 index.html（Vue Router 前端路由需要）
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

> 说明：
> - `proxy_pass http://127.0.0.1:3001;` 不带路径，会原样转发 `/api/health` 到后端，后端路由是 `/api/*`，正好匹配。
> - certbot 会自动在 `listen 80` 上加 `listen 443 ssl` 和证书路径，并加 HTTP→HTTPS 跳转，不用手动改。

## 回滚

如果配置改坏了，随时可以先用旧的「全反代」配置顶回来：

```nginx
server {
    listen 80;
    server_name _;
    location / {
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
    }
}
```
