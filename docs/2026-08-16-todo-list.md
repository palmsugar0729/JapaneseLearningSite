## 一、小程序本地验证（现在就能做 · 手动）

1. 打开 **微信开发者工具**
2. 导入目录：`codes/miniprogram/dist/build/mp-weixin/`（每次改代码后重新 `npm run build:mp-weixin`）
3. 依次过一遍：首页概览、单词（概览/复习/浏览/统计）、练习（设置/答题/结果/错题本）、登录/注册、「我的」
4. 重点验证：复习翻卡→反馈、练习抽题→错题记录、登录后数据是否同步
5. 有报错或交互不对，截图丢到 `assets/bug/` 告诉我

> 开发者工具里勾选 **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**，本地 `localhost:3001` 后端才能连上。

---

## 二、配置小程序 AppID（手动 · 一次性的）

1. 登录 [微信公众平台](https://mp.weixin.qq.com/) → 注册「小程序」账号（个人主体即可）
2. 「开发管理」→「开发设置」里拿到 **AppID**
3. 填入 [manifest.json](../codes/miniprogram/src/manifest.json) 两处：
   - 顶层 `"appid": ""`
   - `"mp-weixin"` 里的 `"appid": ""`
4. 重新 `npm run build:mp-weixin`

> 没有 AppID 也能用「测试号」在开发者工具里预览，但**不能真机预览、不能上线**。

---

## 三、微信登录（接口已就绪 · 待你提供密钥并配置）

小程序端 `uni.login → code` 调用和后端 `/api/auth/wx-login` 接口**都已写好**。剩下的手动步骤：

1. 你到公众平台「开发设置」拿到 **AppID + AppSecret**（Secret 保密，别提交进 git）
2. 服务器上配置环境变量 `WX_APPID`、`WX_SECRET`（PM2 启动时注入，或写 `.env`）
3. 重新部署后端（git pull + `pm2 reload japanese-api`），数据库会自动加 `openid` 列

> 未配置 Secret 时接口会返回「服务器未配置微信登录」，**不影响**账号密码登录。

## 四、域名备案（手动 · 周期最长，建议尽早启动）

**这是上线前的关键路径，周期约 1~2 周（各省不同），建议现在就先提交，和小程序测试并行。**

1. 确认域名 `palmsugar.cn` 已实名认证（在域名注册商处）
2. 登录腾讯云控制台 → **备案**
3. 流程：填主体信息 → 填网站信息（域名 + 接入腾讯云）→ 上传证件 → 人脸核验 → 提交初审 → 管局审核
4. 审核通过拿到 **备案号**
5. 备案号需在网站首页底部展示（可选：小程序后台也要填备案信息）

> 服务器是腾讯云轻量（境内），满足备案「接入商在境内」的要求。

## 五、SSL 证书（备案通过后 · 半自动）

备案通过后，SSH 到服务器执行（参考 [服务器部署指南](服务器部署指南.md)）：

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d jplearning.palmsugar.cn
# 选 2（自动重定向 http→https）
```

Let's Encrypt 自动续期：`certbot renew --dry-run` 验证。
