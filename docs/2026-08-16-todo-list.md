## 一、小程序本地验证（现在就能做 · 手动）

1. 打开 **微信开发者工具**
2. 导入目录：`codes/miniprogram/dist/build/mp-weixin/`（每次改代码后重新 `npm run build:mp-weixin`）
3. 依次过一遍：首页概览、单词（概览/复习/浏览/统计）、练习（设置/答题/结果/错题本）、登录/注册、「我的」
4. 重点验证：复习翻卡→反馈、练习抽题→错题记录、登录后数据是否同步
5. 有报错或交互不对，截图丢到 `assets/bug/` 告诉我

> 开发者工具里勾选 **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**，本地 `localhost:3001` 后端才能连上。

## 二、配置小程序 AppID ✅（已完成）

1. 登录 [微信公众平台](https://mp.weixin.qq.com/) → 注册「小程序」账号（个人主体即可）
2. 「开发管理」→「开发设置」里拿到 **AppID**
3. 填入 [manifest.json](../codes/miniprogram/src/manifest.json) 两处：
   - 顶层 `"appid": ""`
   - `"mp-weixin"` 里的 `"appid": ""`
4. 重新 `npm run build:mp-weixin`

> 没有 AppID 也能用「测试号」在开发者工具里预览，但**不能真机预览、不能上线**。

> 未配置 Secret 时接口返回「服务器未配置微信登录」，**不影响**账号密码登录。

### 操作步骤（SSH 到服务器，一步步来）

**① 登录服务器**

```bash
ssh root@124.221.0.238
```

**② 进后端目录 + 更新代码**

```bash
cd /opt/japanese-learning/JapaneseLearningSite/server
git pull
```

> `git pull` 拉不下来（国内连不上 GitHub）就改用 scp 上传，见 [服务器部署指南](服务器部署指南.md) 3.2 节。

**③ 创建 ecosystem 配置文件**

```bash
nano ecosystem.config.cjs
```

粘贴下面内容（AppID 已填好，`WX_SECRET` 一行替换成你自己的 Secret）：

```js
module.exports = {
  apps: [{
    name: 'japanese-api',
    script: 'node_modules/.bin/tsx',
    args: 'src/index.ts',
    cwd: '/opt/japanese-learning/JapaneseLearningSite/server',
    env: {
      NODE_ENV: 'production',
      WX_APPID: 'wx43f7122b646031a3',
      WX_SECRET: '在这里填你的 Secret',
    },
  }],
}
```

保存退出：`Ctrl+X` → `Y` → `Enter`。

**④ 用新配置重启进程**

```bash
pm2 delete japanese-api
pm2 start ecosystem.config.cjs
pm2 save
```

**⑤ 验证后端**

```bash
pm2 status                    # 应显示 japanese-api 为 online，重启次数不再增加
pm2 logs japanese-api --lines 30
```

- 日志里**不应再出现**「服务器未配置微信登录」。
- 首次微信登录成功时，日志会出现 `[db] migrated: added users.openid`（数据库自动加列）。

**⑥ 小程序端验证**

1. 微信开发者工具 → 重新 `npm run build:mp-weixin`（确认 AppID 已填）
2. 进入「登录」页点「微信一键登录」
3. 成功跳回首页、数据同步 = 通了；账号密码登录不受影响，可并行验证

### ⚠️ 安全提醒

AppSecret **不要写进任何会入库的文件**（`.gitignore` 已排除 `docs/小程序APPID.txt`）。若怀疑已泄露，去公众平台「开发设置」重置 AppSecret 后重新配。
