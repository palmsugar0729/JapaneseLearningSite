## 1. 基础环境配置

> 以下命令都在服务器上执行（SSH 登录后）

### 1.1 更新系统

```bash
apt update && apt upgrade -y
```

### 1.2 设置时区

```bash
timedatectl set-timezone Asia/Shanghai
```

### 1.3 安装基础工具

```bash
apt install -y curl wget git vim ufw build-essential
```

### 1.4 配置防火墙（只开必要端口）

```bash
# 放行 SSH
ufw allow 22/tcp

# 放行 HTTP / HTTPS
ufw allow 80/tcp
ufw allow 443/tcp

# 启用防火墙
ufw enable

# 确认状态
ufw status
```

输出应该类似：
```
Status: active

To                         Action      From
--                         ------      ----
22/tcp                     ALLOW       Anywhere
80/tcp                     ALLOW       Anywhere
443/tcp                    ALLOW       Anywhere
```

> ⚠️ **不要放行 3001 端口**！后端只通过 Nginx 反向代理访问，不直接暴露。

## 2. 安装 Node.js

### 2.1 用 nvm 安装（推荐，方便以后切换版本）

```bash
# 安装 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash

# 重新加载 shell 配置
source ~/.bashrc

# 确认 nvm 装好了
nvm --version

# 安装 Node.js 20 LTS
nvm install 20
nvm use 20
nvm alias default 20

# 验证
node -v    # 应该显示 v20.x.x
npm -v     # 应该显示 10.x.x
```

### 2.2 安装 PM2（进程守护）

```bash
npm install -g pm2

# 设置开机自启
pm2 startup
# 执行它输出的那行命令（sudo 开头的那行）
```

### 2.3 安装 Nginx

```bash
apt install -y nginx

# 开机自启
systemctl enable nginx
systemctl start nginx

# 验证 — 浏览器打开 http://124.221.0.238 应该看到 Nginx 欢迎页
```

## 4. 配置 Nginx 反向代理

### 4.1 创建站点配置

```bash
nano /etc/nginx/sites-available/japanese-api
```

粘贴以下内容：

```nginx
server {
    listen 80;
    server_name _;  # 暂时用 IP 访问，以后换成域名

    # 日志
    access_log /var/log/nginx/japanese-api-access.log;
    error_log  /var/log/nginx/japanese-api-error.log;

    # 反代到 Node.js
    location / {
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;

        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }
}
```

保存退出（`Ctrl+X` → `Y` → `Enter`）

### 4.2 启用站点

```bash
# 创建软链接
ln -s /etc/nginx/sites-available/japanese-api /etc/nginx/sites-enabled/

# 删除默认站点（避免冲突）
rm /etc/nginx/sites-enabled/default

# 检查配置语法
nginx -t

# 重载 Nginx
systemctl reload nginx
```

### 4.3 验证

```bash
# 直接走 80 端口访问 API（不需要带 3001 端口了）
curl http://127.0.0.1/api/health
```

## 5. SSL 证书（备案通过后再做）

> ⚠️ 备案通过之前先跳过这步，用 HTTP + IP 开发测试就行。

### 5.1 安装 certbot

```bash
apt install -y certbot python3-certbot-nginx
```

### 5.2 申请证书（把你的域名替换进去）

```bash
# 先确认域名 DNS 已经指向 124.221.0.238
certbot --nginx -d api.你的域名.com
```

按提示输入邮箱，同意协议即可。certbot 会自动修改 Nginx 配置，加上 HTTPS。

### 5.3 自动续期

```bash
# certbot 安装后会自动添加定时任务，验证一下
systemctl status certbot.timer

# 手动测试续期
certbot renew --dry-run
```

```bash
# SQLite 数据库文件位置
# /opt/japanese-learning/JapaneseLearningSite/server/data/japanese.db
```

## 7. 故障排查

### 网站打不开

```bash
# 1. 检查 node 进程在不在
pm2 status

# 2. 检查 Nginx 在不在
systemctl status nginx

# 3. 检查端口有没有监听
netstat -tlnp | grep -E '3001|80'

# 4. 检查腾讯云控制台防火墙
#    轻量应用服务器 → 实例详情 → 防火墙 → 确认端口规则
```

### PM2 进程异常退出

```bash
pm2 logs japanese-api --lines 50
# 看最后 50 行日志找报错原因
```

### Nginx 报 502 Bad Gateway

说明 Nginx 连不上 Node.js 后端：
```bash
pm2 status        # 确认进程在运行
netstat -tlnp | grep 3001  # 确认 3001 端口在监听
```
