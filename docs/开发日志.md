# 开发日志

## 2026-06-21

### 完成事项

- **项目初始化**：创建 Vue 3 + TypeScript + Vite 日语学习 SPA
- **单词卡 SRS 系统**：SM-2 间隔重复算法，Dashboard/复习/浏览/统计四种模式
- **练习题库**：语法选择 + 翻译题，错题本 + 级别筛选 + 练习历史
- **学习仪表盘**：今日概览卡片、快捷入口、最近学习动态
- **N5~N1 全级别词库**：16,427 词，通过 `import.meta.glob` 加载
- **Fisher-Yates 洗牌**：替换 `sort(() => random - 0.5)` 偏差算法
- **JLPT 级别筛选复习**：按 N5~N1 选择复习范围
- **独立应用拆分**：从 palmsugar-lab 子模块拆为独立项目，移除旧博客文章系统
- **存储前缀更新**：`palmsugar-lab:` → `japanese-learning:`
- **移除 marked 依赖**：随文章系统一起移除
- **学习统计图表**：ECharts 热力图、级别堆叠柱状图、状态环图、正确率趋势折线
- **教科书单词系统**：新编日语教程1 第1~4课数据导入，支持按单元复习
- **用户系统 + SQLite 后端**：Express + better-sqlite3，JWT 认证，注册/登录/登出
- **双模式存储**：登录后 API 存 SQLite，未登录 localStorage 兜底
- **欢迎页**：Welcome.vue 简单着陆页，两个入口卡片
- **顶部导航栏**：sticky 吸顶，首页/背单词/刷题/用户中心/登录/注册
- **每日新词硬上限**：全天最多 10 个新词，跨天重置
- **今日学习任务卡片**：显示任务进度，完成后显示完成状态

### 关键决策

- 数据存储采用双模式：登录 → API + SQLite，未登录 → localStorage 兜底
- ECharts 按需引入以减小打包体积
- 教科书单词复用现有 SRS 引擎，通过 `source`/`unit` 字段区分
- `_token` 从普通变量改为 Vue `ref`，解决退出登录 UI 不响应问题
- 词库 JSON 文件内无 `level` 字段，在 API 层通过文件名注入
