## 二、关键决策与理由

| # | 决策点 | 选择 | 理由 |
|---|--------|------|------|
| 1 | 新题型作答方式 | 填空题、读音题**都用输入框**，答案存 `answer: string[]` | 学习效果最强；数组用于容纳多解（新旧假名写法等）。代价是用户需具备日语输入法 |
| 2 | 违禁词屏蔽 | 本期**不做**，只做长度 + 字符集校验 | 注册量极小，词库维护成本 > 收益；已预留 `contentFilter` 调用点，下期换实现不动业务代码 |
| 3 | 昵称实现 | 直接允许修改 `username`，不新增字段 | 改动最小。**必须**配套处理：改名后重签 token（否则导航栏显示旧名）、重名返回 409 |
| 4 | 访问统计 | busuanzi（布丁统计） | 零开发成本，粘代码即有数据。代价：第三方脚本，隐私政策中须披露 |
| 5 | 本期范围 | **仅 Web 端** | footer / 备案 / busuanzi 均为 Web 独有。注意后端校验改严后**小程序注册会自动跟着变严**（同一接口） |

> **副决策（我定的，如不认可请纠正）**：用户名和密码的**校验规则集中定义在后端**，前端从同一份规则文案实现，避免两边漂移。

## 三、校验规则（本期生效）

### 3.1 用户名

- **长度**：5 ~ 32 个字符（原为 2 ~ 30）
- **允许字符**：中/日文汉字、平假名、片假名、英文字母、数字、下划线 `_`、连字符 `-`
- **不允许**：空格、标点符号、其他符号
- **唯一性**：不变（数据库已有 UNIQUE 约束）

> ⚠️ **兼容性影响**：改严后，**已注册的存量用户不受影响**（只校验新注册和改名），但存量用户名若长度 < 5，其在「修改用户名」时会因不满足新规则而无法保存同名——属预期行为。

### 3.2 密码

- **长度**：≥ 8 个字符（原为 ≥ 4）
- **复杂度**：数字 / 小写字母 / 大写字母 / 特殊字符 四类中，**至少包含三类**
- **特殊字符**：非字母、非数字、非空白的可见符号，如 `!@#$%^&*()_+-=[]{}|;:'",.<>/?~\``

> ⚠️ **存量用户**：已注册用户的旧密码不回溯校验，只在**注册**和**改密码**时生效。

## 四、已知合规缺口（需你知情）

本期**不做内容审核**，即用户名可以填写违禁词汇。项目存在用户注册 + 自定义用户名，属于 UGC 场景，公安备案后若遇检查可能被要求说明内容审核机制。

**已采取的缓解措施**：注册与改名流程中预留 `contentFilter(text)` 调用点，当前为空实现。下期接入词库或云 API 时**只改函数体，不动业务代码**。

**后续可选方案**（按成本排序）：

| 方案 | 成本 | 说明 |
|------|------|------|
| 本地词库 + 归一化匹配 | 低 | `server/src/data/banned-words.txt` 一行一词，匹配前全角转半角、去空格符号、统一小写，防「空 格」绕过 |
| 腾讯云内容安全 API | 中 | 能识别谐音/变体/拆字，需实名开通 + 配密钥，有免费额度 |
| 接入第三方敏感词库 | 低 | npm 中文敏感词库质量参差，需自行筛选 |

## 五、新题型数据结构（**你准备数据时按这个格式填**）

在 `codes/web/src/content/japanese/exercise/` 下新增 JSON 文件（或并入现有 `exercises.json`）。

### 5.1 语法词填空 `fill`

```json
{
  "id": "ex-101",
  "type": "fill",
  "level": "N5",
  "question": "毎日　日本語（　　　）勉強しています。",
  "answer": ["を"],
  "explanation": "「勉強する」是动词，宾语用助词「を」提示。"
}
```

### 5.2 读音练习 `reading`

```json
{
  "id": "ex-201",
  "type": "reading",
  "level": "N5",
  "question": "練習",
  "answer": ["れんしゅう"],
  "explanation": "「練習」读作「れんしゅう」，注意长音。"
}
```

### 5.3 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `id` | ✅ | 全局唯一，格式 `ex-{序号}`，**不要和现有 10 道题重号** |
| `type` | ✅ | `fill` 或 `reading` |
| `level` | ✅ | `N5` / `N4` / `N3` / `N2` / `N1` |
| `question` | ✅ | 填空题：含全角空格占位 `（　　　）` 的整句；读音题：**就填那个词本身** |
| `answer` | ✅ | **字符串数组**，可写多个可接受答案（新旧假名、汉字/假名写法均可） |
| `explanation` | ✅ | 解析，答完展示 |
| `options` | ❌ | 本期不用（已确定全部输入作答） |

### 5.4 判分归一化规则（代码实现，你无需处理）

用户输入与标准答案两边都做同样处理后再比对：

1. 全角字符 → 半角
2. 去掉**所有**空白字符（日文不用空格分隔，去掉更宽松）
3. 片假名 → 平假名
4. 英文字母统一小写
5. 与 `answer` 数组中**任意一项**相等即判对
